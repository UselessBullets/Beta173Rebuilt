*Reconstruction* of Beta 1.7.3's Source Code. Using all the available references I could find. The entire codebase should have largely accurate class, method, field, and local variable names. 
Compiled out values like constants have been re-added. Shadowed dependencies have been taken out to be loaded as a more standard java project would load them.
I have also restored unused functions where they have seemed likely to be in the base B1.7.3 codebase, including some unused code like the DEADMAU camera controls, FLYBY mode, etc.
